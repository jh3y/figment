# Projects

This directory is Figment's source of truth for creative work. Each project belongs under the year in which it was created:

```text
projects/<year>/<slug>/
```

Project folders are intentionally ordinary Markdown, JSON, images, video, and prototype files. They may be committed when their creative history is valuable; this directory is not blanket-ignored.

The repository intentionally ships without a sample project, so a fresh clone is a clean creative workspace. Never reuse or overwrite original reference files in projects you create here.

Creative work belongs to your clone, not to Figment. A studio cloned from Figment is meant to commit its own projects and push them to its own remote, often a private one. The Figment source repository itself never carries creative work, which is why this directory arrives holding nothing but this file.
