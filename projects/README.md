# Projects

This directory is Figment's source of truth for creative work. Each project belongs under the year in which it was created:

```text
projects/<year>/<slug>/
```

Project folders are intentionally ordinary Markdown, JSON, images, video, and prototype files. They may be committed when their creative history is valuable; this directory is not blanket-ignored.

The repository intentionally ships without a full sample project, so a fresh clone is a clean creative workspace. Curated Fig mascot outputs remain under `docs/assets/` as a compact example without bundling the complete generation archive. Never reuse or overwrite original reference files in projects you create here.
